# Product Brief

## Name

Primary recommendation:

**MotionBlock: GIF, Animation & Autoplay Blocker**

Short brand:

**MotionBlock**

## Positioning

Stop distracting motion on web pages without turning the extension into a complicated ad blocker or generic content blocker.

## Initial promise

MotionBlock blocks looping GIFs, GIFV, animated WebP URL patterns, and autoplay-like video. Users can allow or block each media type globally or per website.

## Differentiators

- Per-site preferences from day one.
- Normal WebP images are not blocked by default.
- Current-site controls live in the popup.
- Website rules live in options.
- Compact placeholders avoid the "replacement image is bigger than the original" complaint.
- GIF blocking is page-aware so tiny static GIF interface controls are not treated like distracting animation.
- Autoplay video and muted looping video are treated as motion, not only as media files.
