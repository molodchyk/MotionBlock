# Screenshots

Chrome Web Store screenshot requirements:

- Use PNG or JPEG.
- Use square corners and no padding.
- Use 1280x800 where possible. 640x400 is acceptable if 1280x800 makes the extension UI too small.
- Upload at least one screenshot. Use five screenshots for the first listing so the core value is clear.

Recommended first listing set:

1. `01-popup-current-site-controls.png`
   Show the popup on a normal website with the current-site status, blocked counter, Block motion here, Allow this site, and per-feature rows. This should be the first screenshot because per-site control is the main differentiator from older GIF blockers.

2. `02-options-global-defaults.png`
   Show the options page global defaults grouped into motion blocking and broad media blockers. The image should communicate that GIFs, GIFV, autoplay, video, audio, images, emoji, WebP, and CSS motion are controlled deliberately rather than as one confusing switch.

3. `03-per-site-preferences.png`
   Show the site rules or per-site preferences area with one or two example domains. This directly answers the repeated review request for whitelist/allowlist and per-website settings.

4. `04-blocked-media-placeholders.png`
   Show a neutral test/fixture page with GIF or image/video placeholders and no giant logo. This should demonstrate quiet blocking, preserved layout, and counters. Use the local fixture or a synthetic page, not a branded third-party website screenshot.

5. `05-import-export-sync-theme.png`
   Show backup import/export, Chrome sync wording, and system/light/dark UI mode controls. This screenshot supports trust and settings portability, but it is less important than the first four.

Capture notes:

- Prefer 1280x800 desktop captures.
- Use real extension UI, not mockups.
- Avoid third-party brands, account names, private data, inboxes, social feeds, or copyrighted media.
- Keep browser chrome minimal but visible enough that users understand this is a Chrome extension.
- Do not include unsupported claims such as "best", "number one", or "featured".
- Use the same theme across screenshots unless the screenshot is specifically about theme mode.
- Keep text readable after downscaling to 640x400.

Minimum viable upload if short on time:

1. `01-popup-current-site-controls.png`
2. `02-options-global-defaults.png`
3. `04-blocked-media-placeholders.png`

Keep final screenshots in this folder.
