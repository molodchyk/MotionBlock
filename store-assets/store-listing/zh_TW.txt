在干擾你的 GIFs、 GIFV、自動播放影片、懸浮預覽和頁面動態前，阻擋它們。

使用 MotionBlock 來停止：

影像循環播放 GIF。
GIFV 連結。
短而靜音的影片像 GIFs。
自動播放影片與滑鼠預覽。
可選的動畫 WebP 網址模式。
可選的影片、音訊、圖片、表情符號和 CSS 動態。

MotionBlock 是圍繞每個網站的控制而設計的。保持保守的全域預設值，然後從彈出視窗或選項頁面允許或封鎖個別網站的特定媒體類型。設定會保留在 Chrome 擴充功能同步儲存空間，若使用者啟用擴充功能同步，可能會透過 Chrome 同步。

常見用途：

閱讀時別再干擾動畫。
減少自動播放影片的雜音。
節省頻寬以避免不必要的媒體。
方塊 YouTube 風格的懸浮預覽。
平靜的 Reddit、 Giphy、社群動態，以及將 GIFs 轉為短影片的新聞頁面。
允許大量圖片的網站，同時在其他地方阻擋動態。
迅速允許媒體進入需要的網站。

彈出視窗控制目前的網站。選項頁面管理全域預設值、每個網站偏好設定、 JSON 備份匯入/匯出、阻擋媒體顯示、可選的揭露按鈕，以及明暗/系統介面主題。

Chrome 不允許擴充功能修改瀏覽器內部頁面、 Chrome 網路商店或部分受保護頁面。如果安裝或更改設定後媒體仍可見，請重新載入該頁面。

MotionBlock 不會收集分析資料、將瀏覽資料傳送到伺服器，也不會使用遠端規則清單。
