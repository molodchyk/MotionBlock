विचलित करणारे GIFs, GIFV, ऑटोप्ले व्हिडिओ, होव्हर पूर्वावलोकने आणि पृष्ठ गती आपल्या मार्गात येण्यापूर्वी अवरोधित करा.

थांबविण्यासाठी MotionBlock वापरा:

प्रतिमा GIF लूपिंग.
GIFV दुवे आहेत.
GIFs सारखे लहान निःशब्द व्हिडिओ वापरले जातात.
ऑटोप्ले व्हिडिओ आणि होव्हर पूर्वावलोकन.
पर्यायी अ ॅनिमेटेड WebP URL नमुने.
पर्यायी व्हिडिओ, ऑडिओ, प्रतिमा, इमोजी आणि CSS गती.

MotionBlock प्रति-साइट नियंत्रणाच्या आसपास तयार केले गेले आहे. पुराणमतवादी जागतिक डीफॉल्ट ठेवा, नंतर पॉपअप किंवा पर्याय पृष्ठावरून वैयक्तिक वेबसाइटवर विशिष्ट मीडिया प्रकारांना परवानगी द्या किंवा अवरोधित करा. सेटिंग्ज Chrome विस्तार समक्रमण स्टोरेजमध्ये राहतात आणि वापरकर्त्याने विस्तार सिंक सक्षम केल्यास Chrome द्वारे समक्रमित होऊ शकतात.

सामान्य उपयोग:

वाचताना अ ॅनिमेशन विचलित करणे थांबवा.
ऑटोप्ले व्हिडिओ आवाज कमी करा.
अनावश्यक माध्यमांपासून बँडविड्थ वाचवा.
YouTube-शैली होव्हर पूर्वावलोकने अवरोधित करा.
शांत Reddit, Giphy, सामाजिक फीड आणि बातम्या पृष्ठे जी GIFs लहान व्हिडिओंमध्ये रूपांतरित करतात.
इतरत्र गती अवरोधित करताना प्रतिमा-जड साइट्सना परवानगी द्या.
ज्या साइटवर माध्यमांना आवश्यक आहे अशा माध्यमांना त्वरीत परवानगी द्या.

पॉपअप सध्याच्या साइटवर नियंत्रण ठेवते. पर्याय पृष्ठ जागतिक डीफॉल्ट, प्रति-साइट प्राधान्ये, JSON बॅकअप आयात / निर्यात, अवरोधित मीडिया डिस्प्ले, पर्यायी प्रकट बटणे आणि प्रकाश / गडद / सिस्टम यूआय थीम व्यवस्थापित करते.

Chrome विस्तारांना ब्राउझर-अंतर्गत पृष्ठे, Chrome वेब स्टोअर किंवा काही संरक्षित पृष्ठे सुधारित करण्यास परवानगी देत नाही. सेटिंग्ज स्थापित किंवा बदलल्यानंतरही मीडिया दृश्यमान असल्यास, पृष्ठ पुन्हा लोड करा.

MotionBlock विश्लेषणे गोळा करत नाही, सर्व्हरवर ब्राउझिंग डेटा पाठवत नाही किंवा दूरस्थ नियम सूची वापरत नाही.
