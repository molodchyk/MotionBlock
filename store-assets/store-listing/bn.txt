বিভ্রান্তিকর GIFs, GIFV, অটোপ্লে ভিডিও, হোভার প্রিভিউ এবং পৃষ্ঠার গতি আপনার পথে আসার আগে সেগুলি অবরোধ করুন।

থামাতে MotionBlock ব্যবহার করুন:

GIF চিত্রগুলি লুপ করা।
GIFV লিঙ্ক।
GIFs এর মতো সংক্ষিপ্ত নীরব ভিডিওগুলি ব্যবহৃত হয়েছে।
ভিডিও এবং হোভার পূর্বরূপগুলি স্বয়ংক্রিয় প্লে করুন।
ঐচ্ছিক অ্যানিমেটেড WebP URL প্যাটার্ন।
ঐচ্ছিক ভিডিও, অডিও, চিত্র, ইমোজি এবং CSS গতি।

MotionBlock প্রতি সাইট নিয়ন্ত্রণের চারপাশে নির্মিত। রক্ষণশীল গ্লোবাল ডিফল্টগুলি রাখুন, তারপরে পপআপ বা বিকল্প পৃষ্ঠা থেকে পৃথক ওয়েবসাইটগুলিতে নির্দিষ্ট মিডিয়া প্রকারের অনুমতি দিন বা ব্লক করুন। সেটিংস Chrome এক্সটেনশন সিঙ্ক স্টোরেজে থাকে এবং ব্যবহারকারীর এক্সটেনশন সিঙ্ক সক্ষম থাকলে Chrome এর মাধ্যমে সিঙ্ক হতে পারে।

সাধারণ ব্যবহার:

পড়ার সময় অ্যানিমেশনগুলি বিভ্রান্ত করা বন্ধ করুন।
অটোপ্লে ভিডিও কোলাহল হ্রাস করুন।
অপ্রয়োজনীয় মিডিয়া থেকে ব্যান্ডউইথ সংরক্ষণ করুন।
YouTube-শৈলীর হোভার পূর্বরূপগুলি অবরোধ করুন।
শান্ত Reddit, Giphy, সামাজিক ফিড এবং সংবাদ পৃষ্ঠাগুলি যা GIFs সংক্ষিপ্ত ভিডিওতে রূপান্তর করে।
অন্য কোথাও গতি অবরোধ করার সময় চিত্র-ভারী সাইটগুলিকে অনুমতি দিন।
যে সাইটগুলির প্রয়োজন সেখানে দ্রুত মিডিয়াকে অনুমতি দিন।

পপআপ বর্তমান সাইটটি নিয়ন্ত্রণ করে। বিকল্প পৃষ্ঠাটি বিশ্বব্যাপী ডিফল্ট, প্রতি সাইট পছন্দগুলি JSON ব্যাকআপ আমদানি / রফতানি, অবরুদ্ধ মিডিয়া প্রদর্শন, ঐচ্ছিক প্রকাশ বোতাম এবং হালকা / অন্ধকার / সিস্টেম ইউআই থিম পরিচালনা করে।

Chrome এক্সটেনশনগুলিকে ব্রাউজার-অভ্যন্তরীণ পৃষ্ঠাগুলি, Chrome ওয়েব স্টোর বা কিছু সুরক্ষিত পৃষ্ঠাগুলি সংশোধন করার অনুমতি দেয় না। সেটিংস ইনস্টল বা পরিবর্তন করার পরেও যদি মিডিয়া দৃশ্যমান থাকে তবে পৃষ্ঠাটি পুনরায় লোড করুন।

MotionBlock বিশ্লেষণ সংগ্রহ করে না, সার্ভারে ব্রাউজিং ডেটা প্রেরণ করে না বা দূরবর্তী নিয়ম তালিকা ব্যবহার করে না।
