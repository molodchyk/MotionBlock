ವಿಚಲಿತಗೊಳಿಸುವ GIFs, GIFV, ಆಟೋಪ್ಲೇ ವೀಡಿಯೊ, ಹೋವರ್ ಪೂರ್ವವೀಕ್ಷಣೆಗಳು ಮತ್ತು ಪುಟದ ಚಲನೆಯನ್ನು ಅವು ನಿಮ್ಮ ದಾರಿಯಲ್ಲಿ ಬರುವ ಮೊದಲು ನಿರ್ಬಂಧಿಸಿ.

ನಿಲ್ಲಿಸಲು MotionBlock ಬಳಸಿ:

GIF ಚಿತ್ರಗಳನ್ನು ಲೂಪ್ ಮಾಡುವುದು.
GIFV ಕೊಂಡಿಗಳು.
GIFs ನಂತಹ ಸಣ್ಣ ಮ್ಯೂಟ್ ಮಾಡಿದ ವೀಡಿಯೊಗಳನ್ನು ಬಳಸಲಾಗಿದೆ.
ವೀಡಿಯೊ ಮತ್ತು ಹೋವರ್ ಪೂರ್ವವೀಕ್ಷಣೆಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸಿ.
ಐಚ್ಛಿಕ ಅನಿಮೇಟೆಡ್ WebP URL ಮಾದರಿಗಳು.
ಐಚ್ಛಿಕ ವೀಡಿಯೊ, ಆಡಿಯೋ, ಚಿತ್ರಗಳು, emoji ಮತ್ತು CSS ಚಲನೆ.

MotionBlock ಪ್ರತಿ ಸೈಟ್ ನಿಯಂತ್ರಣದ ಸುತ್ತಲೂ ನಿರ್ಮಿಸಲಾಗಿದೆ. ಸಂಪ್ರದಾಯವಾದಿ ಜಾಗತಿಕ ಡೀಫಾಲ್ಟ್ ಗಳನ್ನು ಇರಿಸಿ, ನಂತರ ಪಾಪ್ ಅಪ್ ಅಥವಾ ಆಯ್ಕೆಗಳ ಪುಟದಿಂದ ವೈಯಕ್ತಿಕ ವೆಬ್ ಸೈಟ್ ಗಳಲ್ಲಿ ನಿರ್ದಿಷ್ಟ ಮಾಧ್ಯಮ ಪ್ರಕಾರಗಳನ್ನು ಅನುಮತಿಸಿ ಅಥವಾ ನಿರ್ಬಂಧಿಸಿ. ಸೆಟ್ಟಿಂಗ್ ಗಳು Chrome ವಿಸ್ತರಣೆ ಸಿಂಕ್ ಸಂಗ್ರಹಣೆಯಲ್ಲಿ ಉಳಿಯುತ್ತವೆ ಮತ್ತು ಬಳಕೆದಾರರು ವಿಸ್ತರಣೆ ಸಿಂಕ್ ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿದ್ದರೆ Chrome ಮೂಲಕ ಸಿಂಕ್ ಮಾಡಬಹುದು.

ಸಾಮಾನ್ಯ ಉಪಯೋಗಗಳು:

ಓದುವಾಗ ಅನಿಮೇಷನ್ ಗಳನ್ನು ವಿಚಲಿತಗೊಳಿಸುವುದನ್ನು ನಿಲ್ಲಿಸಿ.
ಆಟೋಪ್ಲೇ ವೀಡಿಯೊ ಶಬ್ದವನ್ನು ಕಡಿಮೆ ಮಾಡಿ.
ಅನಗತ್ಯ ಮಾಧ್ಯಮದಿಂದ ಬ್ಯಾಂಡ್ ವಿಡ್ತ್ ಉಳಿಸಿ.
YouTube-ಶೈಲಿಯ ಹೋವರ್ ಪೂರ್ವವೀಕ್ಷಣೆಗಳನ್ನು ನಿರ್ಬಂಧಿಸಿ.
ಶಾಂತ Reddit, Giphy, ಸಾಮಾಜಿಕ ಫೀಡ್ ಗಳು ಮತ್ತು ಸುದ್ದಿ ಪುಟಗಳು GIFs ಅನ್ನು ಕಿರು ವೀಡಿಯೊಗಳಾಗಿ ಪರಿವರ್ತಿಸುತ್ತವೆ.
ಬೇರೆಡೆ ಚಲನೆಯನ್ನು ನಿರ್ಬಂಧಿಸುವಾಗ ಇಮೇಜ್-ಭಾರವಾದ ಸೈಟ್ ಗಳನ್ನು ಅನುಮತಿಸಿ.
ಅಗತ್ಯವಿರುವ ಸೈಟ್ ಗಳಲ್ಲಿ ಮಾಧ್ಯಮವನ್ನು ತ್ವರಿತವಾಗಿ ಅನುಮತಿಸಿ.

ಪಾಪ್ ಅಪ್ ಪ್ರಸ್ತುತ ಸೈಟ್ ಅನ್ನು ನಿಯಂತ್ರಿಸುತ್ತದೆ. ಆಯ್ಕೆಗಳ ಪುಟವು ಜಾಗತಿಕ ಪೂರ್ವನಿಯೋಜಿತಗಳು, ಪ್ರತಿ-ಸೈಟ್ ಆದ್ಯತೆಗಳು, JSON ಬ್ಯಾಕಪ್ ಆಮದು / ರಫ್ತು, ನಿರ್ಬಂಧಿತ ಮಾಧ್ಯಮ ಪ್ರದರ್ಶನ, ಐಚ್ಛಿಕ ಬಹಿರಂಗ ಬಟನ್ ಗಳು ಮತ್ತು ಬೆಳಕು / ಗಾಢ / ಸಿಸ್ಟಮ್ UI ಥೀಮ್ ಅನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ.

ಬ್ರೌಸರ್-ಆಂತರಿಕ ಪುಟಗಳು, Chrome ವೆಬ್ ಸ್ಟೋರ್, ಅಥವಾ ಕೆಲವು ಸಂರಕ್ಷಿತ ಪುಟಗಳನ್ನು ಮಾರ್ಪಡಿಸಲು ವಿಸ್ತರಣೆಗಳನ್ನು Chrome ಅನುಮತಿಸುವುದಿಲ್ಲ. ಸೆಟ್ಟಿಂಗ್ ಗಳನ್ನು ಸ್ಥಾಪಿಸಿದ ಅಥವಾ ಬದಲಿಸಿದ ನಂತರವೂ ಮಾಧ್ಯಮ ಗೋಚರಿಸುತ್ತಿದ್ದರೆ, ಪುಟವನ್ನು ಪುನಃ ಲೋಡ್ ಮಾಡಿ.
