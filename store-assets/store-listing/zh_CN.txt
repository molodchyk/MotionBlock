在阻碍你干扰的 GIFs、 GIFV、自动播放视频、悬停预览和页面运动之前，阻止它们干扰你。

用 MotionBlock 来停止：

循环播放 GIF 图像。
GIFV 链接。
短而静音的视频就像用 GIFs。
自动播放视频和悬停预览。
可选的动画 WebP URL模式。
可选视频、音频、图片、表情符号和 CSS 动作。

MotionBlock 是基于每个站点的控制构建的。保持保守的全局默认设置，然后在弹窗或选项页面允许或屏蔽各个网站的特定媒体类型。设置会保留在 Chrome 扩展同步存储中，如果用户启用扩展同步，可能会通过 Chrome 同步。

常见用途：

阅读时别再干扰动画。
减少自动播放视频的噪音。
节省带宽，避免不必要的媒体。
Block YouTube 风格悬浮预览。
平静 Reddit、 Giphy、社交动态和新闻页面，将 GIFs 转换为短视频。
允许大量图片的网站，同时屏蔽其他区域的动态。
快速允许媒体出现在需要的网站上。

弹窗控制当前网站。选项页面管理全局默认设置、每个网站的偏好设置、 JSON 备份导入/导出、阻挡媒体显示、可选的揭示按钮以及明暗/系统界面主题。

Chrome 不允许扩展修改浏览器内部页面、 Chrome Web Store或某些受保护页面。如果安装或更改设置后媒体仍可见，请重新加载页面。

MotionBlock 不收集分析数据，不向服务器发送浏览数据，也不使用远程规则列表。
