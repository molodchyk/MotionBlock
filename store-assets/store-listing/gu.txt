વિચલિત GIFs, GIFV, ઑટોપ્લે વિડિઓ, હોવર પૂર્વાવલોકનો અને પૃષ્ઠ ગતિ તમારા માર્ગમાં આવે તે પહેલાં તેને અવરોધિત કરો.

બંધ કરવા માટે MotionBlock વાપરો:

છબીઓ GIF લૂપ કરી રહ્યા છે.
GIFV કડીઓ.
GIFs જેવા ટૂંકા મ્યૂટ કરેલા વિડિઓઝનો ઉપયોગ કરવામાં આવે છે.
વીડિયો અને હોવર પૂર્વદર્શનો આપોઆપ ચલાવો.
વૈકલ્પિક એનિમેટેડ WebP URL ભાતો.
વૈકલ્પિક વિડિઓ, ઓડિયો, છબીઓ, ઇમોજી અને CSS ગતિ.

MotionBlock પ્રતિ-સાઇટ નિયંત્રણની આસપાસ બનાવવામાં આવ્યું છે. રૂઢિચુસ્ત વૈશ્વિક ડિફોલ્ટ રાખો, પછી પોપઅપ અથવા વિકલ્પો પૃષ્ઠથી વ્યક્તિગત વેબસાઇટ્સ પર ચોક્કસ મીડિયા પ્રકારોને મંજૂરી આપો અથવા અવરોધિત કરો. સેટિંગ્સ Chrome એક્સ્ટેંશન સિંક સ્ટોરેજમાં રહે છે અને જો વપરાશકર્તા પાસે એક્સ્ટેંશન સિંક સક્ષમ હોય તો Chrome દ્વારા સમન્વયિત થઈ શકે છે.

સામાન્ય ઉપયોગો:

વાંચતી વખતે એનિમેશનને વિચલિત કરવાનું બંધ કરો.
ઓટોપ્લે વીડિયો ઘોંઘાટ ઘટાડો.
બિનજરૂરી મીડિયામાંથી બેન્ડવિડ્થ સંગ્રહો.
YouTube-શૈલી હોવર પૂર્વદર્શનોને બ્લોક કરો.
શાંત Reddit, Giphy, સામાજિક ફીડ્સ અને સમાચાર પૃષ્ઠો કે જે GIFs ટૂંકા વિડિઓઝમાં રૂપાંતરિત કરે છે.
અન્યત્ર ગતિને અવરોધિત કરતી વખતે છબી-ભારે સાઇટ્સને મંજૂરી આપો.
સાઇટ્સ પર મીડિયાને ઝડપથી મંજૂરી આપો.

પોપઅપ વર્તમાન સાઇટને નિયંત્રિત કરે છે. વિકલ્પો પૃષ્ઠ વૈશ્વિક ડિફોલ્ટ, પ્રતિ-સાઇટ પસંદગીઓ, JSON બેકઅપ આયાત / નિકાસ, અવરોધિત મીડિયા ડિસ્પ્લે, વૈકલ્પિક જાહેર બટનો અને પ્રકાશ / શ્યામ / સિસ્ટમ UI થીમ મેનેજ કરે છે.

Chrome એક્સ્ટેન્શનને બ્રાઉઝર-આંતરિક પૃષ્ઠો, Chrome વેબ સ્ટોર અથવા કેટલાક સુરક્ષિત પૃષ્ઠોને સુધારવા માટે પરવાનગી આપતું નથી. જો સેટિંગ્સ ઇન્સ્ટોલ કરવા અથવા બદલ્યા પછી પણ મીડિયા દૃશ્યમાન છે, તો પૃષ્ઠને ફરીથી લોડ કરો.

MotionBlock એનાલિટિક્સ એકત્રિત કરતું નથી, સર્વર પર બ્રાઉઝિંગ ડેટા મોકલતું નથી, અથવા દૂરસ્થ નિયમ સૂચિઓનો ઉપયોગ કરતું નથી.
