บล็อก GIFs GIFV วิดีโอเล่นอัตโนมัติ การแสดงตัวอย่างโฮเวอร์ และการเคลื่อนไหวของหน้าเว็บที่รบกวนสมาธิก่อนที่จะมาขวางทางคุณ

ใช้ MotionBlock เพื่อหยุด:

การวนซ้ํา GIF ภาพ
GIFV ลิงก์
วิดีโอปิดเสียงสั้น ๆ ที่ใช้เหมือน GIFs
เล่นวิดีโออัตโนมัติและวางเมาส์เหนือตัวอย่าง
รูปแบบ URL WebP แบบเคลื่อนไหวเสริม
ตัวเลือกวิดีโอ เสียง รูปภาพ อีโมจิ และการเคลื่อนไหว CSS

MotionBlock สร้างขึ้นจากการควบคุมต่อไซต์ รักษาค่าเริ่มต้นส่วนกลางแบบอนุรักษ์นิยม จากนั้นอนุญาตหรือบล็อกสื่อบางประเภทในแต่ละเว็บไซต์จากหน้าป๊อปอัปหรือตัวเลือก การตั้งค่าจะยังคงอยู่ในที่เก็บข้อมูลการซิงค์ส่วนขยาย Chrome และอาจซิงค์ผ่าน Chrome หากผู้ใช้เปิดใช้การซิงค์ส่วนขยาย

การใช้งานทั่วไป:

หยุดภาพเคลื่อนไหวที่ทําให้เสียสมาธิขณะอ่าน
ลดสัญญาณรบกวนของวิดีโอที่เล่นอัตโนมัติ
ประหยัดแบนด์วิดท์จากสื่อที่ไม่จําเป็น
บล็อกการแสดงตัวอย่างโฮเวอร์แบบ YouTube
Reddit Giphy ฟีดโซเชียล และหน้าข่าวที่แปลง GIFs ให้เป็นวิดีโอสั้น ๆ
อนุญาตไซต์ที่มีรูปภาพมากในขณะที่บล็อกการเคลื่อนไหวที่อื่น
อนุญาตสื่อบนเว็บไซต์ที่ต้องการได้อย่างรวดเร็ว

ป๊อปอัปจะควบคุมไซต์ปัจจุบัน หน้าตัวเลือกจะจัดการค่าเริ่มต้นส่วนกลาง ค่ากําหนดต่อไซต์ การนําเข้า/ส่งออกการสํารองข้อมูล JSON การแสดงสื่อที่ถูกบล็อก ปุ่มแสดงตัวเลือก และธีม UI สว่าง/มืด/ระบบ

Chrome ไม่อนุญาตให้ส่วนขยายปรับเปลี่ยนหน้าภายในของเบราว์เซอร์ Chrome เว็บสโตร์ หรือบางหน้าที่มีการป้องกัน หากสื่อยังคงมองเห็นได้หลังจากติดตั้งหรือเปลี่ยนการตั้งค่า ให้โหลดหน้าเว็บอีกครั้ง

MotionBlock จะไม่รวบรวมการวิเคราะห์ ส่งข้อมูลการท่องเว็บไปยังเซิร์ฟเวอร์ หรือใช้รายการกฎระยะไกล
