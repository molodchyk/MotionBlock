気を散らす GIFs、 GIFV、自動再生動画、ホバープレビュー、ページの動きを邪魔になる前にブロックしましょう。

MotionBlock を使って止める:

画像 GIF ループしています。
リンク GIFV。
短くてミュートな動画を使ったの GIFs。
自動再生動画とホバープレビュー。
オプションでアニメーション WebP URLパターンも用意しています。
オプションで動画、音声、画像、絵文字、 CSS モーションもご利用いただけます。

MotionBlock サイトごとの管理を中心に構築されています。保守的なグローバルデフォルトを維持し、ポップアップやオプションページで特定のメディアタイプを許可またはブロックしてください。設定は拡張機能同期ストレージ Chrome 保持され、ユーザーが拡張機能同期を有効にしている場合は Chrome で同期されることがあります。

一般的な用途:

読書中にアニメーションを邪魔するのはやめましょう。
自動再生の動画ノイズを減らしましょう。
不要なメディアから帯域幅を節約しましょう。
ブロック YouTube スタイルのホバープレビュー。
落ち着いた Reddit、 Giphy、ソーシャルフィード、そして短い動画に変換するニュースページ GIFs。
画像が多いサイトを許可しつつ、他の場所は動きをブロックしましょう。
必要なサイトでメディアを迅速に許可しましょう。

ポップアップは現在のサイトを制御します。オプションページでは、グローバルデフォルト、サイトごとの設定、 JSON バックアップインポート/エクスポート、ブロックされたメディア表示、オプションの公開ボタン、ライト/ダーク/システムUIテーマを管理できます。

Chrome 拡張機能がブラウザ内部のページ、 Chrome ウェブストア、または一部の保護されたページを変更することは許可されていません。インストールや設定変更後もメディアがまだ見える場合は、ページを読み込み直してください。

MotionBlock 分析データを収集したり、ブラウジングデータをサーバーに送信したり、リモートルールリストを使用したりしません。
