ശ്രദ്ധ തിരിക്കുന്ന GIFs, GIFV, ഓട്ടോപ്ലേ വീഡിയോ, ഹോവർ പ്രിവ്യൂകൾ, പേജ് മോഷൻ എന്നിവ നിങ്ങളുടെ വഴിയിൽ വരുന്നതിന് മുമ്പ് തടയുക.

നിർത്താൻ MotionBlock ഉപയോഗിക്കുക:

GIF ചിത്രങ്ങൾ ലൂപ്പ് ചെയ്യുന്നു.
GIFV ലിങ്കുകൾ.
GIFs പോലുള്ള ഹ്രസ്വ നിശബ്ദ വീഡിയോകൾ ഉപയോഗിച്ചു.
വീഡിയോയും ഹോവർ പ്രിവ്യൂവുകളും സ്വയമേവ പ്ലേ ചെയ്യുക.
ഓപ്ഷണൽ ആനിമേറ്റഡ് WebP URL പാറ്റേണുകൾ.
ഓപ്ഷണൽ വീഡിയോ, ഓഡിയോ, ഇമേജുകൾ, ഇമോജി, CSS ചലനം.

MotionBlock ഓരോ സൈറ്റിലും നിയന്ത്രണത്തിന് ചുറ്റും നിർമ്മിച്ചിരിക്കുന്നു. യാഥാസ്ഥിതിക ആഗോള സ്ഥിരസ്ഥിതികൾ നിലനിർത്തുക, തുടർന്ന് പോപ്പ്അപ്പ് അല്ലെങ്കിൽ ഓപ്ഷനുകൾ പേജിൽ നിന്ന് വ്യക്തിഗത വെബ് സൈറ്റുകളിലെ നിർദ്ദിഷ്ട മീഡിയ തരങ്ങൾ അനുവദിക്കുകയോ തടയുകയോ ചെയ്യുക. ക്രമീകരണങ്ങൾ Chrome വിപുലീകരണ സമന്വയ സംഭരണത്തിൽ തുടരുന്നു, ഉപയോക്താവിന് എക്സ്റ്റൻഷൻ സമന്വയം പ്രവർത്തനക്ഷമമാക്കിയിട്ടുണ്ടെങ്കിൽ Chrome വഴി സമന്വയിപ്പിച്ചേക്കാം.

പൊതുവായ ഉപയോഗങ്ങൾ:

വായിക്കുമ്പോൾ ആനിമേഷനുകൾ ശ്രദ്ധ തിരിക്കുന്നത് നിർത്തുക.
ഓട്ടോപ്ലേ വീഡിയോ ശബ്ദം കുറയ്ക്കുക.
അനാവശ്യ മീഡിയയിൽ നിന്ന് ബാൻഡ് വിഡ്ത്ത് സംരക്ഷിക്കുക.
YouTube ശൈലിയിലുള്ള ഹോവർ പ്രിവ്യൂകൾ തടയുക.
GIFs ഹ്രസ്വ വീഡിയോകളാക്കി മാറ്റുന്ന ശാന്തമായ Reddit, Giphy, സോഷ്യൽ ഫീഡുകൾ, വാർത്താ പേജുകൾ.
മറ്റെവിടെയെങ്കിലും ചലനം തടയുമ്പോൾ ഇമേജ്-ഹെവി സൈറ്റുകൾ അനുവദിക്കുക.
ആവശ്യമുള്ള സൈറ്റുകളിൽ മീഡിയ വേഗത്തിൽ അനുവദിക്കുക.

പോപ്പ്അപ്പ് നിലവിലെ സൈറ്റിനെ നിയന്ത്രിക്കുന്നു. ഓപ്ഷനുകൾ പേജ് ആഗോള ഡിഫോൾട്ടുകൾ, ഓരോ സൈറ്റ് മുൻഗണനകൾ, JSON ബാക്കപ്പ് ഇറക്കുമതി / കയറ്റുമതി, തടഞ്ഞ മീഡിയ ഡിസ്പ്ലേ, ഓപ്ഷണൽ വെളിപ്പെടുത്തൽ ബട്ടണുകൾ, ലൈറ്റ് / ഡാർക്ക് / സിസ്റ്റം യുഐ തീം എന്നിവ കൈകാര്യം ചെയ്യുന്നു.

ബ്രൗസർ-ആന്തരിക പേജുകൾ, Chrome വെബ് സ്റ്റോർ അല്ലെങ്കിൽ ചില സംരക്ഷിത പേജുകൾ പരിഷ്കരിക്കാൻ വിപുലീകരണങ്ങൾ Chrome അനുവദിക്കുന്നില്ല. ക്രമീകരണങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്തതിന് ശേഷവും അല്ലെങ്കിൽ മാറ്റിയതിന് ശേഷവും മീഡിയ ദൃശ്യമാണെങ്കിൽ, പേജ് വീണ്ടും ലോഡ് ചെയ്യുക.

MotionBlock അനലിറ്റിക്സ് ശേഖരിക്കുകയോ ഒരു സെർവറിലേക്ക് ബ്രൗസിംഗ് ഡാറ്റ അയയ്ക്കുകയോ വിദൂര നിയമ ലിസ്റ്റുകൾ ഉപയോഗിക്കുകയോ ചെയ്യുന്നില്ല.
