கவனத்தை சிதறடிக்கும் GIFs, GIFV, தானியங்கு வீடியோ, மிதவை முன்னோட்டங்கள் மற்றும் பக்க இயக்கம் ஆகியவை உங்கள் வழியில் வருவதற்கு முன்பு அவற்றைத் தடுக்கவும்.

நிறுத்த MotionBlock பயன்படுத்தவும்:

படங்கள் GIF சுழற்றுதல்.
GIFV இணைப்புகள்.
குறுகிய முடக்கப்பட்ட வீடியோக்கள் GIFs போன்ற பயன்படுத்தப்படுகின்றன.
வீடியோவை தானாக இயக்கவும் மற்றும் மிதவை முன்னோட்டங்களையும் இயக்கவும்.
விருப்ப அனிமேஷன் WebP URL வடிவங்கள்.
விருப்ப வீடியோ, ஆடியோ, படங்கள், ஈமோஜி மற்றும் CSS இயக்கம்.

MotionBlock ஒரு தள கட்டுப்பாட்டைச் சுற்றி கட்டப்பட்டுள்ளது. பழமைவாத உலகளாவிய இயல்புநிலைகளை வைத்திருங்கள், பின்னர் பாப்அப் அல்லது விருப்பங்கள் பக்கத்திலிருந்து தனிப்பட்ட வலைத்தளங்களில் குறிப்பிட்ட மீடியா வகைகளை அனுமதிக்கவும் அல்லது தடுக்கவும். அமைப்புகள் Chrome நீட்டிப்பு ஒத்திசைவு சேமிப்பகத்தில் இருக்கும், மேலும் பயனர் நீட்டிப்பு ஒத்திசைவு இயக்கப்பட்டிருந்தால் Chrome மூலம் ஒத்திசைக்கலாம்.

தானியங்கு வீடியோ சத்தத்தைக் குறைக்கவும்.
தேவையற்ற ஊடகங்களிலிருந்து அலைவரிசையை சேமிக்கவும்.
YouTube பாணி மிதவை முன்னோட்டங்களைத் தடுக்கவும்.
அமைதியான Reddit, Giphy, சமூக ஊட்டங்கள் மற்றும் செய்தி பக்கங்களை குறுகிய வீடியோக்களாக மாற்ற GIFs ும்.
வேறு இடங்களில் இயக்கத்தைத் தடுக்கும் போது பட-கனமான தளங்களை அனுமதிக்கவும்.
தேவைப்படும் தளங்களில் மீடியாவை விரைவாகச் அனுமதிக்கவும்.

பாப்அப் தற்போதைய தளத்தை கட்டுப்படுத்துகிறது. விருப்பங்கள் பக்கம் உலகளாவிய இயல்புநிலைகள், ஒரு தள விருப்பத்தேர்வுகள், JSON காப்புப்பிரதி இறக்குமதி/ஏற்றுமதி, தடுக்கப்பட்ட மீடியா காட்சி, விருப்ப வெளிப்படுத்தல் பொத்தான்கள் மற்றும் ஒளி/இருண்ட/கணினி UI கருப்பொருள் ஆகியவற்றை நிர்வகிக்கிறது.

உலாவி-உள் பக்கங்கள், Chrome வலை அங்காடி அல்லது சில பாதுகாக்கப்பட்ட பக்கங்களை மாற்ற நீட்டிப்புகளை Chrome அனுமதிக்காது. அமைப்புகளை நிறுவிய அல்லது மாற்றிய பிறகும் மீடியா இன்னும் தெரியும் என்றால், பக்கத்தை மீண்டும் ஏற்றவும்.
