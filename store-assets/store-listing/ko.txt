방해가 되는 GIFs, GIFV, 자동 재생 영상, 호버 미리보기, 페이지 움직임 등을 방해하기 전에 차단하세요.

MotionBlock 사용해서 멈추세요:

이미지를 반복 GIF.
GIFV 링크.
짧고 음소거된 영상들이 GIFs 같은 용도로 사용되었습니다.
자동 재생 영상과 호버 미리보기.
선택 가능한 애니메이션 WebP URL 패턴.
선택적으로 비디오, 오디오, 이미지, 이모지, CSS 동작 등이 가능합니다.

MotionBlock 사이트별 제어를 중심으로 구축되어 있습니다. 보수적인 글로벌 기본값을 유지하고, 팝업이나 옵션 페이지에서 개별 웹사이트의 특정 미디어 유형을 허용하거나 차단하세요. 설정은 Chrome 확장 프로그램 동기화 저장소에 보관되며, 사용자가 확장 프로그램 동기화를 활성화하면 Chrome 동기화가 가능할 수 있습니다.

일반적인 용도:

읽을 때 애니메이션을 방해하지 마세요.
자동 재생 비디오 노이즈를 줄이세요.
불필요한 미디어로부터 대역폭을 절약하세요.
블록 YouTube 스타일의 호버 미리보기.
차분한 Reddit, Giphy, 소셜 피드, 그리고 GIFs 를 짧은 영상으로 변환하는 뉴스 페이지.
이미지가 많은 사이트는 허용하고, 다른 곳은 움직임을 차단하세요.
필요한 사이트에 미디어를 신속히 허용하세요.

팝업이 현재 사이트를 제어합니다. 옵션 페이지는 전역 기본값, 사이트별 환경설정, JSON 백업 가져오기/내보내기, 차단된 미디어 표시, 선택적 공개 버튼, 그리고 밝은/다크/시스템 UI 테마를 관리합니다.

Chrome 확장 프로그램이 브라우저 내부 페이지, Chrome 웹 스토어, 또는 일부 보호된 페이지를 수정하는 것을 허용하지 않습니다. 설치하거나 설정을 변경한 후에도 미디어가 여전히 보이면 페이지를 다시 불러오세요.

MotionBlock 분석을 수집하거나 서버에 탐색 데이터를 전송하거나 원격 규칙 목록을 사용하지 않습니다.
